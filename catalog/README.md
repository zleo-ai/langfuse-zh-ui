# 二级界面文案目录

`secondary.zh-CN.json` 是本地 0.3.0 的可维护文案来源。`translated` 为审核过的静态文案；`dynamic-template` 为包含名称、数字等变量的源模板，实际运行由 `translate.js` 中有界规则处理；`preserved` 为品牌、协议、代码示例、用户数据或可编辑的默认内容，保留原文并注明原因。

`locations` 指向 Langfuse 固定提交的 `web/src/` 下源码位置；补充条目的 `file` 可指向本轮本地 `frame-*.json` 界面记录。界面记录保存在仓库忽略的 `workspace/langfuse-zh-secondary-20261105`，不打入扩展离线包。

源码提取不是全站可达性证明。企业功能、未配置服务或没有记录才能进入的页面，以报告中的“源码检查/未实测”为准。品牌、模型/工具/项目名称、用户输入、原始 JSON、代码与日志不计作界面漏译。

`hover.zh-CN.json` 是 0.3.1 悬停专项目录，固定同一 Langfuse 4.75.0 提交，收录原目录遗漏的 278 条处理决策：271 条补译，7 条代码示例、语言名、文件名或品牌保留。`supportedKeys` 为本轮提取到且确认属于界面的 519 条文案，包含此前已译部分，用于识别悬停浮层中的静态界面说明。原始数据触发的同名悬停、代码及 Markdown 仍不翻译。

提取范围是源码中的 `headerTooltip`、提示内容、说明标题和原生 `title` 等可识别静态文案。首轮 228 条；实际触发页面发现 `help` 中带链接的 JSX 片段另需提取，扩展后 284 条；再将没有 Tooltip 组件但带原生 title 的文件纳入，最终共 526 条。它不代表所有动态拼接、条件分支、服务端错误或第三方内嵌界面。
