# Langfuse 4.75.0 中文覆盖审计

本次覆盖审计固定到 Langfuse `v4.75.0`，提交 `fd1605c762db572669321eb1f989aa566b6883ed`。扫描客户端 JSX、控件属性、说明、通知、校验错误及动态模板，排除企业目录、服务端目录、API 路由和测试。具体扫描逻辑见 `scripts/extract-ui.mjs`。

`catalog/source-inventory.json` 保留 8956 个源码位置记录。`catalog/*.zh-CN.json` 保存译文、源码位置、动态参数与保留理由。`npm run test:catalog` 要求每条扫描结果都有词条或明确处理决定，未处理项会导致检查失败。动态规则只匹配已审核的完整模板，名称和数值作为参数保留，不执行源码表达式。

本轮新增审查包含 3055 条静态候选及 342 条动态候选。品牌、代码、示例提示词、用户命名数据、机器标识、开发诊断和不可见页面元数据有明确保留理由。保留原文不等于漏译，也不会用空字符串把遗漏隐藏掉。

本地实际浏览器运行：原有主界面 85 项、二级界面 81 项、悬停 47 项，以及新增覆盖与数据保护检查。新增检查包含 2675 条静态文案和 606 组动态提示样例；批量匹配不等于 3281 个真实页面，也不等于中文语义已获得外部用户验收。

对源码没有出现的新文案、不同版本、服务端返回的未知错误、自定义内容、第三方内嵌界面或浏览器原生界面，不作零英文承诺。企业功能没有实际验收。扩展只处理已识别的 Langfuse 页面，代码、输入框值、富文本及原始数据区域受保护。

贡献者补词时，应同时增加正向界面用例、同名数据保护和恢复用例。不要为提高覆盖率翻译 API 标识、修改可编辑默认提示词、放开原始数据区或移除排除规则。
